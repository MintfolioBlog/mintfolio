# 博客功能一览

这一页说明 Mintfolio 构建时会替你生成什么。这些功能和主题无关，换哪个主题都有；至于页面上怎么展示，由主题决定。

## 生成的页面

| 地址 | 内容 |
| --- | --- |
| `/` | 首页 |
| `/about` | 关于我，用的是 `site.config.ts` 里的个人资料 |
| `/blog`、`/blog/page/2` | 全部文章，按页拆分 |
| `/blog/<文章>` | 文章 |
| `/tags/<标签>`、`/categories/<分类>`、`/series/<系列>` | 标签、分类、系列页，同样会分页 |
| `/<页面>` | `_mintfolio/pages/` 里的独立页面 |
| 旧地址 | 文章 `aliases` 里写的旧地址，打开后跳转到新地址 |
| `/404.html` | 找不到页面 |

文章排序：置顶的在前，其余按发布时间从新到旧。分页是真实的静态页面，不开 JavaScript 也能翻。

标签、分类名里有中文或特殊字符没关系，地址会自动编码。

## 搜索

全站全文搜索，能搜到标题、摘要和正文。

它不需要任何搜索服务：构建时生成一个 `/search-index.json`，读者第一次搜索时浏览器才去加载，然后在本地查询。支持多个关键词（同时包含才算命中）、结合标签和分类筛选、高亮匹配的文字。

搜索不到的东西：草稿、还没到时间的文章、设置了 `seo.noindex` 的文章、密码文章的正文。

内容非常多时，索引文件会变大，可以参考 [内容规模基准](https://github.com/MintfolioBlog/mintfolio/blob/main/docs/performance.md) 评估。

## 订阅和 SEO

| 地址 | 内容 |
| --- | --- |
| `/rss.xml` | RSS 2.0 |
| `/atom.xml` | Atom 1.0 |
| `/feed.json` | JSON Feed 1.1 |
| `/sitemap.xml` | 站点地图 |
| `/robots.txt` | 声明 Sitemap 的位置 |

订阅默认只放摘要，`feed.content: 'full'` 改成全文（会去掉脚本和交互内容，阅读器里能正常看）。订阅按发布时间排序，置顶不影响。

每个页面都会带上 canonical、Open Graph、Twitter Card，文章还有结构化数据（`BlogPosting`）。分享图优先用文章的 `seo.image`，其次是封面，最后是站点的 `seo.defaultSocialImage`。

不进订阅和 Sitemap 的：草稿、未来的文章、密码文章、`seo.noindex` 的文章。

`noindex` 只是让搜索引擎别收录，知道地址的人照样能打开。真要保密请用密码。

## 阅读相关

- **字数和阅读时长**：自动统计，中文按字、英文按词，每分钟 240 字估算。代码块不算。
- **相关文章**：根据系列、标签、分类自动挑选。
- **上一篇 / 下一篇**、**系列目录**：按发布顺序和系列顺序排好。
- **宽表格**：自动包上可横向滚动的容器，手机上不会撑破页面。

## 检查内容

```sh
mintfolio check
```

发布前跑一下，它会找出：

- 站内链接指向不存在的文章或页面
- 引用了不存在的图片
- 两篇文章抢同一个地址

还会以警告的形式提示可能有问题的锚点链接。它不会联网检查外部链接。加 `--json` 可以给 CI 读取。

## 草稿预览

`mintfolio dev --drafts` 在本地连草稿和未来文章一起显示，页面上会标着“本地预览”。这个开关只对本地开发有效，正式构建永远不会带上草稿。
